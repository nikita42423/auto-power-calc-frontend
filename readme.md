# Auto power calc frontend

SPA на `React` + `TypeScript` (сборщик `Vite`) с компонентами `React-Bootstrap`.
Интерфейс для **гостя**: просмотр услуг (устройств автомобиля) — их мощности и сопротивления.
Данные карточек берутся только из коллекции `mock`-объектов (`src/entities/device/model/mock.ts`), бэкенд не используется.

## Общие элементы всех страниц

- **Статус-бар** сверху (время и значки) — макет экрана телефона из лаб. 1.
- **Навигационная панель** снизу из 4 пунктов:

| Пункт | Адрес | Доступность |
|---|---|---|
| 📱 Лента | `/feed` | доступен |
| 📝 Добавление | — | недоступен (серый) |
| 📊 Плитка | `/grid` | доступен |
| 🔑 Вход | — | недоступен (серый) |

Пункт текущей страницы выделен красным цветом и серым фоном.

## Страница «Лента» — `/feed` и `/feed/:id`

Одна услуга на весь экран.

- `/feed` — первая опубликованная услуга, `/feed/:id` — услуга с указанным id.
- Если услуги с таким id нет или она не опубликована, происходит переход на «Плитку».

| Элемент | Тип | Назначение |
|---|---|---|
| Видео | фон | видео услуги на весь экран (автовоспроизведение, без звука, по кругу); если поле пустое — видео по умолчанию |
| «Мощность … Вт / Сопротивление … Ом» | текст | характеристики устройства |
| 👍 и число | значок | количество лайков (для гостя только просмотр) |
| ➜ | кнопка | переход к следующей опубликованной услуге (после последней — снова первая) |
| Название, описание, «Еще» | текст | название и описание услуги (описание обрезано до 2 строк) |

## Страница «Плитка» — `/grid`

Каталог опубликованных услуг карточками в две колонки и фильтр по мощности.

| Элемент | Тип | Назначение |
|---|---|---|
| «Каталог устройств» | заголовок | — |
| Левый ползунок | поле (range) | минимальная мощность, 0–2000 Вт, шаг 10 |
| Правый ползунок | поле (range) | максимальная мощность, 0–2000 Вт, шаг 10 |
| «🔎 Найти» | кнопка | применяет фильтр: остаются услуги с мощностью в выбранном диапазоне |
| «Мощность: от … до … Вт» | текст | текущие значения ползунков |
| Карточка услуги | ссылка | изображение (или изображение по умолчанию), «мощность Вт \| сопротивление Ом», название, 👍 лайки; нажатие открывает услугу в «Ленте» |

При открытии страницы показываются все опубликованные услуги. Если оставить диапазон 0–2000 и нажать «Найти», снова показываются все.

## Структура проекта

```
src/
  main.tsx                      точка входа, роутер
  app/App.tsx                   общий макет: статус-бар, страница, navbar
  app/styles.css                стили из лаб. 1
  pages/FeedPage/               страница «Лента»
  pages/GridPage/               страница «Плитка»
  widgets/TabBar/               нижняя навигационная панель
  widgets/StatusBar/            верхний статус-бар
  features/PowerFilter/         фильтр по мощности
  entities/device/model/        тип Device и mock-коллекция
  entities/device/ui/           карточка услуги DeviceCard
  shared/assets/                изображение и видео по умолчанию
```
